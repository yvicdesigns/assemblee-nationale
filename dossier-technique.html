Section 01

Résumé Exécutif
& Architecture Technique

01
Le site de l'Assemblée Nationale de la République du Congo est un portail institutionnel de nouvelle génération, conçu selon les standards internationaux les plus élevés. Il offre une vitrine officielle, rapide et sécurisée pour la 15ᵉ Législature, entièrement administrable par les équipes internes sans aucune compétence technique requise.
Architecture Jamstack
⚡
Frontend Statique
Construit en HTML5 / CSS3 / JavaScript vanilla — sans framework lourd. Pages pré-rendues et distribuées via CDN mondial. Chargement en moins d'une seconde depuis n'importe quel pays du monde, sans serveur applicatif à maintenir.
🗄
Backend Cloud — Supabase
Toutes les données (articles, députés, agenda, contacts) sont stockées dans une base PostgreSQL hébergée sur Supabase. Accès sécurisé par JWT et Row Level Security. Médias stockés dans Supabase Storage.
🌍
CDN Global — Vercel
Hébergement assuré par Vercel, réseau de plus de 100 points de présence mondiaux. Le site est répliqué automatiquement sur tous les continents. Un visiteur à Brazzaville, Paris ou New York charge le site à la même vitesse.
🔐
Sécurité Multicouche
HTTPS forcé avec HSTS 2 ans, authentification JWT pour l'admin, Row Level Security PostgreSQL, en-têtes HTTP anti-XSS et anti-clickjacking, robots.txt protégeant le panneau d'administration.

Système CMS —
Panneau d'Administration

03
Le tableau de bord d'administration est un CMS complet, sécurisé et intuitif accessible uniquement aux équipes autorisées de l'Assemblée Nationale. Il permet de gérer l'intégralité du contenu du site sans jamais toucher au code source.
Modules disponibles dans le Dashboard
📰
Articles & Publications
Créer, modifier, publier ou archiver des articles. Éditeur riche avec blocs (texte, images, citations, listes). Gestion des catégories et des brouillons avant publication.
🖼
Carrousel / Diapositives
Ajouter ou modifier les diapositives de la page d'accueil. Upload d'images, titre, sous-titre, lien d'action. Ordre d'affichage configurable.
📅
Agenda Parlementaire
Planifier les sessions, réunions et événements de l'Assemblée. Date, heure, lieu, description. Affichage automatique sur la page d'accueil.
👤
Présidence & Bureau
Mettre à jour les profils du Président et des membres du Bureau (Vice-Présidents, Secrétaires, Questeurs). Photo, biographie, circonscription.
👥
Gestion des 151 Députés
Fiche complète pour chaque député : nom, département, circonscription, groupe parlementaire, photo officielle. Recherche et filtres intégrés. Upload photo direct.
✉️
Messages de Contact
Consulter tous les messages reçus via le formulaire. Marquer comme lu, exporter. Les visiteurs anonymes peuvent envoyer sans être inscrits.
🖼
Médiathèque
Gestionnaire de fichiers centralisé. Upload d'images et documents organisés par dossiers. Stockage illimité via Supabase Storage.
📄
Pages Personnalisées
Créer des pages institutionnelles supplémentaires avec éditeur par blocs (EditorJS). Slug personnalisé, méta-description SEO. Statut brouillon / publié.

Options Recommandées selon les Besoins
🥇 Option A — Vercel + Supabase (Recommandé)
Solution actuelle. 0 serveur à gérer, déploiement automatique depuis GitHub, CDN mondial, SSL gratuit. Supabase assure la base de données PostgreSQL avec backups automatiques. Coût : ~20–50 $/mois pour un site à fort trafic. Idéal pour démarrer.
🥈 Option B — Hostinger (Domaine + Email)
Recommandé pour l'achat du nom de domaine officiel (ex. assemblee-nationale.cg) et la messagerie email officielle (@assemblee-nationale.cg). Interface simple, prix compétitifs en Afrique.
🥉 Option C — Hetzner (VPS pour Indépendance)
Hetzner (Allemagne, RGPD) propose des serveurs dédiés à bas coût. Recommandé si l'Assemblée souhaite héberger ses propres serveurs en Europe. Nécessite un administrateur système qualifié. Excellente option pour la souveraineté des données.
❌ À Éviter — Hébergement Local Congo
Risques majeurs : coupures d'électricité, bande passante insuffisante pour le trafic international, absence de CDN, SSL coûteux, absence de backups automatiques. Un site institutionnel de l'Assemblée Nationale ne peut pas se permettre ces risques.

Section 05

Sécurité & Performance

05
Architecture de Sécurité — 6 Niveaux de Protection
Critique
HTTPS Forcé avec HSTS (2 ans)
Toutes les communications entre le visiteur et le serveur sont chiffrées par TLS. L'en-tête HSTS force le HTTPS pour les 2 prochaines années, empêchant toute connexion non chiffrée. Le certificat SSL est renouvelé automatiquement sans intervention humaine.
Critique
Authentification JWT — Accès Admin Sécurisé
L'accès au panneau d'administration est protégé par des tokens JWT (JSON Web Token) signés et à durée d'expiration. Un administrateur dont le compte est compromis peut être révoqué instantanément. Aucun mot de passe en clair ne transite sur le réseau.
Critique
Row Level Security (RLS) PostgreSQL
La base de données impose des règles d'accès au niveau de chaque ligne de données. Les visiteurs anonymes ne peuvent lire que le contenu publié et actif. Il est techniquement impossible pour un visiteur malveillant d'accéder aux brouillons, messages de contact ou données administratives.
Élevé
En-têtes HTTP de Sécurité
5 en-têtes HTTP de sécurité configurés sur Vercel : X-Frame-Options (anti-clickjacking), X-Content-Type-Options (anti-MIME injection), X-XSS-Protection (anti-injection de scripts), Referrer-Policy (protection vie privée), Permissions-Policy (désactivation caméra, micro, géolocalisation).
Standard
Robots.txt — Protection du Panneau Admin
Le fichier robots.txt exclut explicitement le répertoire /admin/ de l'indexation par tous les moteurs de recherche. Le panneau d'administration n'apparaît jamais dans les résultats Google ou Bing et n'est pas découvrable par les robots malveillants.
Standard
Protection DDoS — Intégrée Vercel (Enterprise)
Vercel intègre nativement une protection anti-DDoS de niveau enterprise. En cas d'attaque visant à saturer le site, le trafic malveillant est automatiquement filtré. Le site reste accessible au public sans aucune intervention manuelle.

Section 06

Avantages Compétitifs
& Feuille de Route

06
Nos Avantages Compétitifs
🌍 Visibilité Internationale
Grâce au CDN mondial de Vercel, le site est aussi rapide depuis Paris, Washington ou Pékin que depuis Brazzaville. La diaspora congolaise et la presse internationale y accèdent sans friction. Un hébergement local ne peut pas offrir cette expérience.
📱 100% Responsive Mobile
Le site est entièrement optimisé pour smartphones et tablettes — plus de 70% des Congolais naviguent sur mobile. Menu hamburger, carrousel tactile, formulaires adaptés. Aucun concurrent utilisant un CMS générique n'atteint ce niveau d'optimisation.
🔧 Zéro Maintenance Serveur
Contrairement à un serveur dédié ou un hébergement classique, notre architecture Jamstack ne nécessite aucune mise à jour de système d'exploitation ni gestion de base de données locale. Tout est géré automatiquement.
⚡ Déploiement en 30 Secondes
Toute modification du code est automatiquement déployée via GitHub → Vercel en moins de 30 secondes. Pas de FTP, pas de connexion SSH. L'équipe technique peut corriger un problème ou ajouter une fonctionnalité en temps réel.
🎨 Design Institutionnel Professionnel
Interface aux couleurs officielles de la République du Congo (vert, jaune, rouge), logo officiel intégré, charte graphique cohérente sur toutes les pages. Un design qui reflète le sérieux et la dignité de l'institution parlementaire.
🔍 SEO Optimisé — Google
Sitemap XML soumis aux moteurs de recherche, balises méta sur chaque page, vitesse de chargement optimale (Core Web Vitals), HTTPS (critère de classement), robots.txt configuré. Excellent positionnement Google garanti.
