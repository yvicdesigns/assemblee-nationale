Contexte & Besoin
Compréhension de la mission

L'Assemblée Nationale de la République du Congo, institution représentant les 151 députés élus au suffrage universel direct, nécessitait une présence numérique à la hauteur de son rôle constitutionnel. Dans un contexte de transformation digitale des institutions africaines, disposer d'un site web officiel sécurisé, accessible et moderne est devenu une exigence de transparence démocratique.

« La démocratie numérique exige que les institutions parlementaires soient visibles, accessibles et sécurisées pour les citoyens, au-delà des frontières physiques. »

— Objectif stratégique de la 15ᵉ Législature

Sécurité & Protection
Architecture conçue pour résister aux attaques
⚠ Contexte : incidents de sécurité passés
Suite aux piratages et défacements subis par des sites institutionnels congolais, notre architecture a été conçue dès le départ pour éliminer les vecteurs d'attaque les plus courants. Chaque décision technique répond à une menace réelle.
Mesures de sécurité implémentées
Critique
Architecture Jamstack statique
Pas de serveur PHP, pas de WordPress, pas de CMS standard. 90 % des piratages de sites institutionnels exploitent des vulnérabilités PHP/WordPress. Notre site ne peut pas être défacé de cette façon.
Zéro base de données exposée publiquement
Zéro exécution de code côté serveur
Zéro plugin tiers vulnérable
Critique
Administration totalement isolée
L'interface d'administration est sur une URL non indexée, protégée par authentification Supabase. Le fichier robots.txt interdit l'indexation de /admin/.
URL admin non devinable
Authentification Supabase (JWT)
Exclue des moteurs de recherche
Important
HTTPS forcé sur toutes les pages
Vercel impose HTTPS automatiquement. Toutes les communications sont chiffrées TLS 1.3. Impossible d'accéder au site en HTTP non sécurisé.
Certificat SSL renouvelé automatiquement
TLS 1.3 — chiffrement moderne
Redirection HTTP → HTTPS automatique
Important
Protection des données personnelles
Aucun numéro de téléphone ni adresse privée des députés n'est stocké ou affiché publiquement. Les données sensibles restent dans la base de données sécurisée.
Numéros de téléphone masqués
Accès données par rôle (RLS Supabase)
Logs d'accès admin conservés
Hébergement sécurisé — Vercel CDN

Vercel est l'infrastructure utilisée par des gouvernements et grandes entreprises mondiales. Les fichiers sont distribués depuis 200+ points de présence dans le monde, rendant une attaque DDoS inefficace. Disponibilité contractuelle : 99,99 %.
